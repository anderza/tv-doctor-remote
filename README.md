# TV Doctor — улучшенная версия

Приложение для Android-телефона, которое по Wi-Fi подключается к Smart TV и помогает навести порядок в телевизоре.

## Основные возможности (из оригинала)
- Сканирование системы: память, диск, температура, нагрузка
- Поиск и удаление мусора, рекламы, телеметрии
- Очистка кэша в один тап
- Установка APK с телефона на ТВ
- Журнал действий с возможностью отмены

## ✨ Мои улучшения (предложения)

### 1. Компактное окно сортировки
Окно «Сортировка по памяти / Обновить» при нажатии на кнопку «Приложения» сейчас слишком большое. Нужно сделать его компактным и аккуратным.

### 2. Иконки приложений
Напротив каждого приложения в списке должны отображаться его картинки (иконки). Это упростит визуальный поиск.

### 3. Блокировка рекламы и покупок Google
Добавить возможность отключать не только рекламу, но и встроенные покупки от Google (in-app purchases) в приложениях на телевизоре.

### 4. Имитация пульта ДУ
Добавить экран с виртуальным пультом: стрелки, кнопка ОК, Назад, Домой, Громкость, Меню. Чтобы управлять телевизором прямо с телефона.
